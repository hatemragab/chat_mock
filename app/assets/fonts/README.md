# Bundled fallback fonts

These fonts keep the prototype's typography, reactions, emoji and symbols available offline in builds and development runs.

- **Noto Emoji**, copyright 2013 Google LLC: [official font source](https://github.com/google/fonts/tree/main/ofl/notoemoji). License: `NotoEmoji-OFL.txt` (SIL Open Font License 1.1).
- **Noto Sans Symbols**, copyright 2022 The Noto Project Authors: [official font source](https://github.com/google/fonts/tree/main/ofl/notosanssymbols). License: `NotoSansSymbols-OFL.txt` (SIL Open Font License 1.1).
- **Roboto Regular**, bundled from the installed Flutter SDK's material fonts: [official project](https://github.com/googlefonts/roboto). License: `Roboto_LICENSE.txt` (Apache License 2.0).

The TTF files are unmodified copies. All licenses are included in the application assets.
